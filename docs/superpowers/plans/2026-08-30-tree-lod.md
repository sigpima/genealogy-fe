# Tree Level-of-Detail by Depth Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Reduce family-tree render cost by drawing full detail (avatar + name) only for members within 3 hops of the member the user last interacted with, and name-only for everyone else.

**Architecture:** A pure `computeDetailSet(root, focalId, radius)` function BFS's the family tree — treating parent-child edges as undirected — from a "focal" member out to `radius` hops, returning the set of member ids that should render with full detail. `GenealogyTree` tracks the focal id in state (updated on expand/collapse toggle and on search-select), memoizes the detail set, and branches its existing `renderNode` on membership in that set to skip the avatar/`clipPath`/fallback-initial block for out-of-radius members.

**Tech Stack:** Next.js 15, React 19, TypeScript, `react-d3-tree` (unchanged), Vitest (new test file, existing setup).

**Spec:** `docs/superpowers/specs/2026-08-30-tree-lod-design.md`

## Global Constraints

- Hops are counted on undirected parent-child edges — a focal node's radius extends to both its ancestors and its descendants, per the spec's Goals.
- The radius is a fixed constant (3), not user-configurable, per the spec's Non-goals.
- No change to `nodeSize`/layout spacing — name-only nodes occupy the same rect, per the spec's Non-goals.
- `npx tsc --noEmit` must pass (0 errors) after every task.
- No new automated UI/interaction tests — visual behavior is verified by running `npm run dev` and checking in a browser, per the spec's Non-goals (consistent with this repo's existing testing approach).

Create `src/lib/tree/lod.ts`:

```ts
import type { FamilyMember } from './types';

function buildAdjacency(root: FamilyMember): Map<number, number[]> {
  const adjacency = new Map<number, number[]>();

  function ensure(id: number): number[] {
    let neighbors = adjacency.get(id);
    if (!neighbors) {
      neighbors = [];
      adjacency.set(id, neighbors);
    }
    return neighbors;
  }

  function walk(node: FamilyMember, parentId: number | null) {
    if (node.id === undefined) return;
    ensure(node.id);
    if (parentId !== null) {
      ensure(parentId).push(node.id);
      ensure(node.id).push(parentId);
    }
    node.children?.forEach((child) => walk(child, node.id ?? null));
  }

  walk(root, null);
  return adjacency;
}

export function computeDetailSet(
  root: FamilyMember,
  focalId: number,
  radius = 3
): Set<number> {
  const adjacency = buildAdjacency(root);
  const startId = adjacency.has(focalId) ? focalId : root.id;
  const detailed = new Set<number>();
  if (startId === undefined) return detailed;

  detailed.add(startId);
  let frontier = [startId];
  for (let hop = 0; hop < radius; hop++) {
    const next: number[] = [];
    for (const id of frontier) {
      for (const neighbor of adjacency.get(id) ?? []) {
        if (!detailed.has(neighbor)) {
          detailed.add(neighbor);
          next.push(neighbor);
        }
      }
    }
    frontier = next;
  }
  return detailed;
}
```
